Billboard.com-Spotify-Playlist

## Uses 
Scrapes Billboard.com's top 100 songs of 2025 and creates a Spotify playlist of them

## Implementation
uses Spotify API, Spotipy library, OAuth Authentication

Must create a Spotify App using "[Spotify for Developers.com](https://developer.spotify.com/)"
to get "client_id" and "client_secret" to utilize the Spotify API and Spotipy in the program
